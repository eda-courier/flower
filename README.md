# Тепловая карта заказов цветов

Готовый статический сайт. Для публикации создайте репозиторий GitHub, загрузите содержимое этого архива в корень ветки `main` (включая папку `vendor`), затем откройте Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save. Адрес появится в Settings → Pages. Для Краснодара добавьте `#krasnodar` к адресу сайта.

Для локального просмотра: `python -m http.server 8080`, затем http://localhost:8080/.

Данные исходной исторической выгрузки не изменены. Даты скрыты в интерфейсе; карта не является оперативной статистикой. Картографическая подложка загружается из OpenStreetMap через интернет. Перед публикацией согласуйте раскрытие агрегированных данных: публичный репозиторий и сайт доступны всем.
